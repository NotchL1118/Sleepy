## 已确认的产品决定

- 以连续阅读技术长文的舒适度为主，代码和表格保持适度紧凑。
- 普通文章与心作暂时共用排版。正文、代码块、表格、图片和 Mermaid 使用同一内容宽度，块级容器左右对齐，不允许向正文两侧突出。小图片和小图形可保持自然尺寸，不强制拉伸。
- 纸张纹理保持原样。延续现有无衬线正文、等宽代码字体和深浅主题方向。
- 代码默认保留原始行结构，在块内横向滚动；提供自动换行切换。复制操作始终复制原始源码。
- Mermaid 默认展示图形，点击图形本身或“放大”按钮均可进入铺满浏览器内容区的放大视图；支持图形与源码切换、复制源码、滚轮／双指缩放、拖拽平移、适应窗口、100%、Esc关闭和焦点返回。
- 目录收录正文 h1–h4，有标题就显示；h5–h6 不收录，文章名称不重复收录。所有层级始终展开，无折叠箭头；整份目录共用一条连续竖线，当前标题在同一条线上高亮。保留层级缩进、标题跳转和独立滚动。
- Studio 预览完整对齐发布效果，包括排版、代码高亮、代码操作和 Mermaid。分栏按可用宽度响应；纯预览使用与公开内容相同的最大宽度。
- 首期提供统一默认样式并兼容浏览器缩放，不增加读者字号或宽度设置。
- 本次接入普通文章、心作和 Studio；共享 Markdown 能力供未来页面内容复用，页面管理留待后续。

## 首版验证参数（设计提案）

以下参数已在样张确认后用于正式实现，不是经读者实验得出的最佳值。px换算以16px根字号为例；实现使用相对单位。

| 部位 | 首版起点 |
| --- | --- |
| 内容最大宽度 | 45rem，约720px；正文及所有块级内容共用同一上限 |
| 手机边距 | 保留约18px左右边距，内容宽度不超出可用空间 |
| 正文 | 桌面17px / 1.8；手机16px / 1.8；段后约1em |
| 标题 | h2约26px / 1.35，h3约21px / 1.45；标题前距大于后距；连续标题收紧间距；h1–h6保持可辨层级 |
| 列表与引用 | 紧凑列表条目间约0.25em；多段引用恢复段间距，末段不留多余下距 |
| 行内代码 | 正文字号约0.9倍；轻量背景和内边距；只作用于行内代码 |
| 代码块 | 14px / 1.6，内边距约16px；与行内代码样式隔离，未高亮时也保持相同排版 |
| 表格 | 正文与表头约14px / 1.6，表头通过字重区分；保留大小写；按内容分配列宽，宽表在容器内滚动 |
| 字体 | 保留Geist和Geist Mono方向，检查中文系统回退与中英混排；本轮不引入新的字体文件 |

## Mermaid 与代码的建议行为

以下工程默认值已用于正式实现；真实图种和交互已通过浏览器验证。

1. 将明确标记为 `mermaid` 的 fenced code 交给专用图表组件；普通代码继续走语法高亮。公开内容与预览共享分类规则、样式和交互。
2. Mermaid 按需加载，支持所选官方版本内置的标准图种；以中文流程图、时序图、类图、ER图、状态图作为首期验证样本，不额外引入第三方图种扩展。
3. 图形跟随站点深浅主题，默认使用站点统一配色和字体。普通阅读视图保持统一内容边界；放大视图铺满浏览器内容区，按 SVG 原始宽高适应画布，通过缩放和平移查看细节，支持键盘关闭和焦点返回。
4. 加载与解析失败时保留可读源码；单张图的错误不阻断整篇文章。无JavaScript时源码仍可读；本轮提案采用客户端图表渲染，不增加预生成SVG管线。
5. 多图具有独立标识；主题切换、快速编辑或卸载时，旧渲染结果不得覆盖最新内容。避免字体尚未就绪导致标签裁切。
6. 使用受控配置及默认严格安全级别，不为普通图表开放任意HTML或执行图内脚本。识别并保留支持的无障碍标题与描述。
7. 普通代码提供复制、换行切换和必要的语言标识；不增加行号、SVG下载或独立图表编辑器。

## 验收标准

- 用同一份中文技术文章在公开内容和Studio预览中比较：包含中英混排、h1–h6、嵌套列表、多段引用、行内代码、无语言和未知语言代码块、长命令、宽表、图片和脚注。
- 正文、代码、表格、图片与图形容器始终共用左右边界；局部横滚不会使整个页面变宽；目录与正文不重叠。
- 检查320px、常见手机和桌面宽度，以及Studio分栏和纯预览。检查200%文字放大、等效320px回流与适用的文字间距覆盖，不出现内容丢失或操作不可达。
- 深浅主题均可辨识正文、代码、表格和图形，纸张纹理参数保持原样。
- Mermaid验证中文标签、多图、重复源码、大图、无效语法、主题切换、快速编辑和组件卸载；错误后仍能阅读并复制源码。
- 复制结果保留原始换行和缩进；自动换行只改变展示。按钮可用键盘操作，放大查看可关闭且焦点返回触发按钮。
- 按实际改动执行类型检查、lint及必要的行为测试；完成桌面和手机视觉验证。未执行的验证必须在交付时明确说明。

## 2026-09-11：全屏图形与目录迭代

用户在单 HTML 样张中确认了全屏图形交互，并将目录收敛为 h1–h4、连续竖线、没有右侧折叠箭头。正式实现保留独立可滚动目录及当前章节高亮。

- 图形按 SVG viewBox 计算初始比例，支持宽图、竖图及原始尺寸；围绕指针或双指中心缩放，平移不触发整页滚动。适应窗口随画布尺寸变化重新计算，自由浏览时保留当前缩放。

- 目录保留所有标题参与锚点编号，因此被排除的 h5/h6 不会破坏后续同名 h1–h4 的链接。阅读位置计算覆盖标题之间的长段落，以及图形、图片加载引发的位置变化。
